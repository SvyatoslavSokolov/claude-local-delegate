## 🏛️ Двухзвенная архитектура (Two-Tiered Architecture)

> **Принцип:** интерактивный Архитектор (Tier 1) + автономный локальный кластер из 4x RTX 3090 (Tier 0).

- **Tier 1 — Interactive Architect** (гипервизор): платные модели Claude Code, Antigravity и Codex. Здесь живёт принятие архитектурных решений и оркестрация; контекст экономится за счёт делегирования.
- **Tier 0 — Local Workers (4x 3090):** автономный кластер с vLLM / LiteLLM. Выполняет исследования, правки и проверки по делегированным атомарным задачам; его результаты всегда ревьюятся Архитектором.
- **Смысл:** вся «мушечная» работа уводится на бесплатные локальные воркеры, а на платной модели остаётся только архитектура и финальный обзор.
